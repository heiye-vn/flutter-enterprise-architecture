# Flutter 企业级开发学习文档（面向前端开发者）

> 目标：从零学完 Flutter，达到**企业级应用开发**水准——不是"能跑个 Demo"，而是能独立承担一个生产 App 的架构设计、功能开发、测试、优化与发布全流程。

## 这套文档适合谁

- 有 1 年以上前端经验（Vue / React / 小程序均可），熟悉组件化、状态管理、路由等概念
- 想通过 Flutter 做**跨端开发**（iOS / Android，兼顾 Web / 桌面）
- 目标是写出**可维护、可测试、可扩展**的企业级代码，而不是堆砌 API 的示例代码

## 学习方法建议

1. **对照着学**：文档大量使用"相当于前端里的 XXX"的对照写法，遇到新概念先映射到已有知识，再理解差异。
2. **跟练优先**：每篇的代码示例都按企业目录习惯组织（`lib/features/...`），强烈建议新建一个项目边读边敲，不要只看不写。
3. **先会用，再求懂**：第一遍过 01–08 篇时允许"知其然"，09 篇（架构）之后再回头看渲染原理、状态选型，理解会深很多。
4. **报错是常态**：Flutter 报错信息质量较高，学会读日志、用 DevTools、查官方文档是核心技能，遇到 API 疑问以 [docs.flutter.dev](https://docs.flutter.dev) 为准。

## 前端 → Flutter 心智迁移总表

| 前端概念 | Flutter 对应 | 差异要点 |
|----------|--------------|----------|
| 组件（Component） | Widget | Widget 是**不可变**的轻量描述，重建成本极低 |
| 虚拟 DOM | Element 树 | 不做全量 diff 对比，Element 复用 + 局部重建 |
| `package.json` | `pubspec.yaml` | 依赖 + 资源声明 + Flutter SDK 约束三合一 |
| npm / pnpm | pub | 国内可配镜像 |
| vue-router / React Router | go_router | 声明式路由，支持重定向守卫 |
| Pinia / Redux / Zustand | Riverpod / Bloc / Provider | 状态不挂在组件树顶层，依赖注入式 |
| axios 拦截器 | dio 拦截器 | 思路一致，401 刷新 Token 套路可直接迁移 |
| localStorage | shared_preferences | 异步 API，不能存大对象 |
| IndexedDB | Hive / sqflite | Hive 面向对象，sqflite 面向 SQL |
| Web Worker | Isolate | 内存不共享，只能消息传递 |
| Babel / TS 编译 | AOT / JIT | 开发 JIT 热重载，发布 AOT 编译为机器码 |
| CSS 布局 | Widget 组合布局 | 没有 CSS，一切靠嵌套组件实现（Flex 是核心） |

## 版本说明

- **核对基准：2026-11-11**，对应 **Flutter 3.47.x / Dart 3.13**（依据官方中文站 [docs.flutter.cn](https://docs.flutter.cn/) 与 [dart.cn](https://dart.cn/)）。
- 生态包版本以 pub.dev 当日为准，本系列主要对齐：**go_router 18.x**、**flutter_riverpod 3.5.x**、**dio 5.x**。
- Flutter 迭代非常快：**升级前请先看[版本演进与迁移速查](16-版本演进与迁移速查.md)**，那里有 3.16 → 3.47 与本系列相关的全部破坏性变更、替代 API 和一条命令搞定的迁移方式（`dart fix --apply`）。
- 遇到编译报错或参数不匹配：**第一反应是查该包在 pub.dev 的 CHANGELOG 与官方示例**，而不是搜旧教程。2023–2024 年的大量中文文章还在教已废弃的写法（`withOpacity`、`package:flutter_gen`、Riverpod 2.x 的 `StateProvider`），照抄会浪费时间。
- 本系列涉及的三处"新老写法差异最大"的地方，已在正文标出：组件库拆包（[04 篇 4.1](04-Widget与布局.md)）、配色角色与 `withValues`（[04 篇 9.1](04-Widget与布局.md)）、Riverpod 3.x 迁移（[06 篇 5.2.1](06-状态管理.md)）。
